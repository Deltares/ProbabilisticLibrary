\chapter{Introduction}

This document gives a scientific background for optimization methods that are in use in geotechnical software
and software related to flood defense. Some of these methods are used indirectly by the Probabilistic Library,
e.g. in Cobyla Reliability.

\section{Overview of this document}

\Autoref{sec:Optimization} gives an overview of the optimization algorithms implemented in the Probabilistic Library.
It describes grid search and grid refinement, the genetic algorithm, Adaptive Particle Swarm Optimization, Cobyla, and K-Means clustering.
For each algorithm, the relevant concepts and procedure are explained in relation to minimization or partitioning problems encountered in geotechnical and flood-defense applications.
